Questions about our coverage area

How do I know if my ZIP code is covered?

Find your town in the list below. Each town's page names its own ZIP code or codes. If you do not see your town, call and we will check.

Do you charge more to travel to farther towns?

We quote after an inspection, the same as for Puyallup itself. Distance is one factor among several, never a flat surcharge we can quote over the phone.

Is the emergency line the same number for every town?

Yes. One line covers Puyallup and every town on this list, open 24/7.

What if my town is not its own city, or is a military installation?

That is fine. We serve the address and ZIP code, not a town hall. Each unincorporated community's or military-adjacent page explains how coverage works there.
